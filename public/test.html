Widget Test Page (Local Dev)

This page tests the FeedbackFlow widget against your local Next.js server (http://localhost:3000). All API calls go to your local Supabase instance.

⚠️ Before you test

  • Make sure npm run dev is running on port 3000
  • Replace PASTE_YOUR_KEY_HERE in the script tag below with your real public_key — find it in Project Settings → Installation or the Supabase Studio → projects table
  • Access this page via http://localhost:3000/test.html (not file://) so the widget API calls work

Checklist

  • Widget button appears (correct color, text, position)
  • Clicking the button opens the feedback panel
  • Submitting a message creates a row in Supabase → feedback table
  • Auto-detected fields populated (browser, OS, device, screen size)
  • An invalid public_key shows an error message in the widget

Verify Installation Test

  • Go to the onboarding wizard or Installation Guide page in your dashboard
  • Set your project's website URL to http://localhost:3000 in Supabase Studio
  • Click Check installation — the server will fetch http://localhost:3000/test.html is NOT checked, but http://localhost:3000 (the homepage) is. Make sure your homepage also has the widget script tag, or update the website_url to http://localhost:3000/test.html
