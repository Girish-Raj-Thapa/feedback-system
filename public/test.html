Widget Test Page

This page tests the FeedbackFlow widget. The floating button should appear in the bottom-right corner once the widget loads.

Make sure your dev server is running at http://localhost:3000 and replace PASTE_YOUR_PUBLIC_KEY_HERE below with your real public_key from the Project Settings page.

Checklist

  • Widget button appears (correct color, text, position)
  • Clicking the button opens the feedback panel
  • Submitting a message creates a row in Supabase → feedback table
  • Auto-detected fields are populated (browser, OS, device, screen size)
  • An invalid public_key shows an error message in the widget
